# Project Skills Registry

This repository stores project-level skills under `.agents/skills/`.

## Directory rule
- One skill per directory: `.agents/skills/<skill-name>/`
- Required files per skill:
  - `skill.yaml`
  - `README.md`

## Lifecycle
1. Discover: scan `.agents/skills/*/`
2. Install: follow each skill README
3. Use: record skill name/version/purpose in task notes
